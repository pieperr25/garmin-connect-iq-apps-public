# Garmin Connect IQ Apps

Personal Garmin Connect IQ projects, initially targeting the Edge 540.

## Apps

- [`apps/wind-field`](apps/wind-field) — a cycling data field that shows current
  wind speed and rotates an arrow to show where the wind is coming from relative
  to the bike's direction of travel.
- [`apps/drivetrain-friction-governor`](apps/drivetrain-friction-governor) — a
  cycling data field that warns about electronic-shifting cross-chaining.

## Repository layout

```text
apps/       Connect IQ application projects
docs/       Shared design and setup notes
tools/      Local validation helpers
```

The apps are intended for private sideloading.
